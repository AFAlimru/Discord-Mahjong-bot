# 🀄 雀月 Suzume Tsuk — Discord 日本麻雀ボット

> 🤖 このプロジェクトは **vibe coding**（AI 支援開発）で作られています。

Discord の中で本格ルールの日本麻雀（立直麻雀）を遊べるボットです。四人打ち／三人打ち、東風戦／半荘戦、ボイスチャンネルでの自動マッチング、サーバーをまたいだ段位戦とフリー対戦、CPU 対戦に対応。牌は**カスタム絵文字**で表示され、操作は**ボタン**で行います。

## ✨ 主な機能

- **牌のカスタム絵文字＋ボタン操作**：牌はアップロードした Discord アプリケーション絵文字で表示。自分の番では手牌がそのまま打牌ボタンになり、チー／ポン／カン／ロン／ツモ／リーチ／抜きドラもボタンで操作できます。**黒い牌デザイン**は段位「日全食」到達で解放（`/mahjong skin`）。
- **完全な点数計算**：42 種の役＋七対子・国士無双、鳴きによる食い下がり、役なしでは和了不可、符計算と点数（標準精算）。
- **状況役**：立直／一発／ダブル立直、海底／河底、嶺上開花、槍槓、天和／地和。
- **ルール設定**：喰い替え禁止（既定）、**オープンリーチ**（2 翻＋手牌公開、放銃すると役満）、**途中流局**のオン／オフ、ミックス／天鳳ルール。
- **フリテン**：捨て牌／同巡／リーチ後フリテン（鳴かれた牌も含む全捨て牌で判定）。パネルにフリテン・役なし・一部役なしを常に表示。
- **三人打ち**：108 枚、抜きドラ（北）、チーなし。
- **半荘・東風の通し対局**：連荘／本場、供託、ノーテン罰符、トビ、最終順位のウマ精算。
- **途中流局**：九種九牌、四風連打、四家立直、四槓散了、三家和（ルールでオフにでき、その場合も流し満貫は有効）。
- **ダブロン**、加槓／槍槓、暗槓／大明槓。
- **CPU 対戦相手**：向聴数と有効牌で打牌し、誰かがリーチしたら守備、テンパイならリーチ、むやみに鳴かない。
- **ボイスマッチング**：「🔊 友人戦を作成」ボイスに入ると 4 人用のボイス部屋が自動で作られ、ルーム設定パネルがその部屋のテキストチャットに表示されます。満員で自動開始（3 人ならそのまま三麻、人数が足りなければ「🤖 CPUと開始」で空席を CPU が埋めます）。対局が終わると部屋は自動で削除されます。
- **キャラボイス**：各プレイヤーが自分のボイスパックを選べ、ポン・リーチ・和了・役名などを声で読み上げます。CPU の声は部屋主が `/mahjong ai_voice` で設定します（音声ファイルはソースに含まれていません。作り方は下記）。
- **カテゴリ式ロビー**：`/setup create`（またはセットアップガイドの「🏗️ ロビーを作成」）で「雀月麻雀」カテゴリを作成——読み取り専用のボタンロビー、💬 テキストチャンネル（部屋作成・雑談用）、🔊 マッチングボイス。対局チャンネルもカテゴリ内に作られ、終了後に自動削除されます。言語ごとにロビーを作ることができ、どのロビーから部屋を開いたかでその言語が使われます。
- **手牌パネルを DM で**：待機画面で「📩 手牌をDMで」を押すと、その対局の手牌パネルが DM に届きます。
- **段位戦（サーバー横断）**：`/mahjong rank` でグローバルマッチング（**近い段位同士のみ**）、対局は DM で行います。月蝕テーマの段位（新人 → … → 血月、血月以外は各段位 1～3 に分かれる）と R 値。ルールは天鳳ルール、牌山は天鳳方式で固定です。
- **フリー対戦**：`/mahjong match` でサーバーをまたいで対戦相手を集めます（段位なし）。
- **CPU と遊ぶ**：ボットに DM で `/mahjong start` を送ると、CPU で席を埋めてすぐ開始。
- **放置対策**：タイムアウトが続くと自動でツモ切りになり、ボタン一つで復帰できます。全員が放置状態になると対局を終了します。
- **牌譜とリプレイ**：`/mahjong history` で過去の対局を 1 局ずつ見られ、そのままリプレイも可能。`/mahjong replay <部屋コード>` で対局をコマ送り再生（手牌・和了演出・視点切り替え）。部屋コードは 5 文字（例：`K7Q2M`）。
- **戦績とタスク**：`/mahjong stats`、`/mahjong profile`、デイリーチェックインとアクティブ度。ウェブサイトでさらに詳しいデータを確認できます。
- **公平性**：公開されている 2 つの牌山生成方式（麻雀一番街／天鳳）から選択。局ごとに牌山エンコード＋SHA-256 のコミットメント（`/mahjong fairness`）があり、対局終了後に完全なエンコード（天鳳方式はシードファイルも）を公開するので、対局ごとに検証できます。
- **安定性**：チャンネル対局はボット再起動後に復元。DM 対局は再起動で終了します。
- **多言語**：繁体字中国語／日本語／英語。`/language` で切り替え。スラッシュコマンドの説明は Discord のクライアント言語に合わせて表示されます。

## 🚀 インストールと起動

**仮想環境**での実行を推奨します。**Python 3.10 以上**が必要です。

```bash
# 1. 仮想環境を作成して有効化
python -m venv .venv
#    Windows (PowerShell):  .venv\Scripts\Activate.ps1
#    macOS / Linux:         source .venv/bin/activate

# 2. 依存パッケージをインストール
pip install -r requirements.txt

# 3. .env を設定（トークンを記入。各項目は .env.example を参照）
cp .env.example .env        # Windows: copy .env.example .env

# 4. 起動（データベースは起動時に自動で初期化されます）
python run.py
```

> ⚠️ 初回起動の前に、[Discord Developer Portal](https://discord.com/developers/applications/) →
> 対象のアプリケーション → **Bot → Privileged Gateway Intents** で **Message Content Intent** を有効にしてください。

### 牌の絵文字をアップロード（任意ですが強く推奨）

牌の絵文字は**あなた自身のボットアプリケーション**に紐づくため、自分のトークンで一度アップロードしてください（未アップロードの場合は Unicode の牌で表示されます）：

```bash
pip install pymupdf pillow "discord.py>=2.4"
python tools/build_and_upload_emojis.py          # 白 38 枚
python tools/build_and_upload_emojis.py black    # 黒 38 枚（段位報酬のデザイン）
```

> 生成される `mahjong/tile_emojis*.json` は**そのボット専用で、別の環境にコピーしてはいけません**（gitignore 済み）。

### キャラボイス（任意）

- ホストに **FFmpeg** をインストールしてください（PATH に通す）。FFmpeg がない場合ボイスは自動で無効になり、対局には影響しません。
- `assets/sounds/` のサブフォルダ 1 つが 1 つのボイスパック（フォルダ名＝パック名）、ファイル名＝音声名です（例：`riichi.mp3`、`立直.ogg`）。
- プレイヤーはロビーの「🎚️ ボイス」で自分のパックを選びます。行動した人の声で再生され、放置中のプレイヤーは無音です。
- CPU の声は `/mahjong ai_voice`（または「🎚️ ボイス」の 2 つ目のメニュー）で設定し、自分が部屋主のボイス部屋対局に適用されます。未設定なら CPU は無音です。

## 🕹️ 主なコマンド

| コマンド | 説明 |
|------|------|
| `/mahjong start` | 部屋を作る（チャンネルで友人と／ボットへの DM なら CPU と対戦） |
| `/mahjong join` | このチャンネルの部屋に参加。DM ではサーバー横断のフリー対戦 |
| `/mahjong rank` | 段位戦のグローバルマッチング（対局は DM） |
| `/mahjong match` | フリー対戦のマッチング（段位なし） |
| `/mahjong end` | 対局を強制終了（部屋主はそのまま終了、他のプレイヤーは部屋主の承認が必要） |
| `/mahjong status` · `/mahjong fairness` | 現在の対局状況 · 牌山のコミットメント（公平性の検証） |
| `/mahjong stats` · `/mahjong profile` | 統計 · プロフィールカード |
| `/mahjong history` · `/mahjong replay <部屋コード>` | 牌譜（◀ ▶ で切り替え、そのままリプレイ可） · リプレイ |
| `/mahjong daily` · `/mahjong tasks` | デイリーチェックイン · タスク |
| `/mahjong yaku` · `/mahjong rankinfo` | 役一覧 · 段位の説明（各段階の必要 pt と順位ごとの増減） |
| `/mahjong skin` · `/mahjong notify` | 牌デザイン · マッチング通知 |
| `/mahjong ai_voice` | CPU のボイス（自分が開いたボイス部屋対局で CPU が使う声） |
| `/setup create` · `/setup channel` | 雀月カテゴリを作成（ロビー＋テキストチャンネル＋マッチングボイス） · プレイ用チャンネルの指定 |
| `/setup lang` · `/setup clear_room` | サーバーのメイン言語 · 残った対局／待機部屋の削除 |
| `/help` · `/language` | ヘルプ · 言語 |

> `/setup` 系のコマンドには「**サーバー管理**」権限が必要です。ボットをサーバーに追加すると**管理者だけが見える**「セットアップガイド」チャンネルが作られるので、その手順に沿って始められます（ボットに足りない権限もガイドに表示されます）。

## ⚙️ ルーム設定

部屋のパネルで次の項目を変更できます：**対局の長さ**（東風／半荘）、**トビ**、**三人打ち**、**ルール**（ミックス／天鳳）、**喰い替え**（禁止／あり）、**オープンリーチ**（なし／あり）、**途中流局**（あり／なし）、**牌山生成**（麻雀一番街／天鳳）、**持ち時間**、**配給原点**。段位戦は天鳳ルール・天鳳牌山で固定です。

## 🙏 出典・クレジット

- **牌山の生成と公平性の検証**（実装は `mahjong/engine.py`）：
  - **麻雀一番街（Riichi City）**が公開している牌山方式（既定）——暗号学的に安全な乱数で Fisher–Yates シャッフルを行い、
    牌山全体を順番に文字列化（例：`1m2p3s7z…`）して SHA-256 をコミットメントとし、対局終了後に完全なエンコードを公開します。
  - **天鳳**が公開している牌山生成方式（[tenhou.net/stat/rand](https://tenhou.net/stat/rand/)）——624 個のシードで MT19937 を初期化し、
    乱数を SHA-512 に通してからシャッフル。天鳳公式の検証データと照合し、牌山が完全に一致することを確認済みです。
    コミットメントは同じく牌山エンコードの SHA-256 で、対局終了後にシードも公開するので、天鳳のサンプルコードで同じ牌山を再現できます。
- **牌の画像**：[FluffyStuff/riichi-mahjong-tiles](https://github.com/FluffyStuff/riichi-mahjong-tiles)。
  `tools/build_and_upload_emojis.py` がダウンロードして Discord 絵文字に変換します。
